# TrainingVR

Небольшой VR-тренажёр обслуживания электрооборудования.

## Требования

- Unity 6.3.11f1
- OpenXR
- Input System
- XR Interaction Toolkit
- Addressables

## Запуск

Открыть проект в Unity и запустить сцену `Assets/_Project/Scenes/Menu.unity`.
Сцена тренировки `BasicScene` загружается через Addressables целиком.

## Сценарий

1. Отключить питание рубильником.
2. Взять и установить автомат.
3. Взять отвёртку и обработать две рабочие зоны.
4. Включить питание.
